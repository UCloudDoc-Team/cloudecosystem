# 基础概念

**镜像类商品**<br />
由服务商 ISV（Independent Software Vendor）提供的收费镜像及相关服务。通过将应用软件与云资源结合，实现用户对云服务器即开即用。


**SaaS 类商品**<br />
SaaS 类商品是指由服务商 ISV（Independent Software Vendor）提供的在线应用软件及相关服务。用户无需购买独立的云资源，只需购买 SaaS 应用即可登录到指定平台使用商品。
目前SaaS类商品接入时，使用用户名+初始密码的方式开通商品。即用户在云生态CloudEcosystem 购买商品时，云生态调用服务商提供的生产系统接口地址，实施账号注册和资源购买操作，并返回交付平台登录地址、用户名、密码等信息。

**服务类商品**<br />
服务类商机是服务商 ISV（Independent Software Vendor）提供的人工服务、私有化软件、定制化服务等商品，例如运维管理、跨境咨询等。
目前，此类商品通过人工线下交付模式进行服务履约。用户在云生态CloudEcosystem 完成下单后，平台将指派专属交付资源，与用户对接并开展线下交付工作，确保服务的顺利实施与落地。

**规格**<br />
云生态产品可按不同规格进行售卖，规格用于区分产品在交付方式、功能模块、配置参数、版本类型及计费模式等方面的差异。适用场景有：免费试用场景、产品分版本销售场景、个性化定制场景。一款商品可设置多个规格，每个规格仅支持一种交付方式。

**交付方式**<br />
交付方式指云生态商品提供给用户的使用与部署形式，不同交付方式决定了用户如何获取、安装和使用产品。云生态当前支持以下几种交付方式：
- 镜像：产品以预配置的云端镜像形式提供，用户可在云环境中一键部署。
- SaaS ：产品以在线SaaS服务或API接口形式交付，用户无需自行部署，可直接访问或调用。
- 线下交付：产品由服务商通过线下方式交付，包括定制安装、配置或现场部署。<br />


**服务商**<br />
云市场的产品提供方，即服务商 ISV（Independent Software Vendor），可以是提供专业解决方案的商业公司，也可以是在 AI、安全、大数据等领域的开发者或者个人爱好者。服务商利用自身的专业能力和资源，为云市场 UMarketplace 提供各类镜像产品和服务。
