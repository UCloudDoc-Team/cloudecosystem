# 计费说明

## 计费项
云生态 CloudEcosystem 根据您选购的商品价格及使用时长或使用量进行计费。

| 类型 | 计费模式 | 计费说明 |
| --- | --- | --- |
| 收费商品 | 按天/按月/按年/按量/一次性（支持代金券） | 1. 镜像类商品：每款收费镜像都有其单独设定的价格，用户使用的费用根据所选镜像价格、使用时长计费。 镜像商品价格请参考控制台 [云主机购买页](https://console.ucloud.cn/uhost/uhost)。<br/>2. 非镜像类商品，每款商品分多种规格，每个规格有其独立的计费方式和价格，根据所选的一个或多个规格计费。商品价格参考 [云生态购买页](http://www-v2-pre.prj-console.svc.c1.u4/cloudecosystem)。</font>  |


镜像类商品需要部署于云主机实例，云主机 UHost 的计费可参考相关的 [计费说明](/uhost/buy/charge)。 



## 计费模式
云生态 CloudEcosystem当前仅支持预付费，允许使用代金券，但不支持后付费。不同商品可能涉及多种计费模式，常见的计费模式有：

+ 订阅制计费：<font style="color:rgba(0, 0, 0, 0.85);">计费周期将根据商品所支持的选项，以及您在下单时实际选购的周期来确定，支持按天、按月、按年的方式。镜像类商品常采用此类计费方式。</font>
+ 按量计费：根据实际使用量动态计费，用多少付多少，如资源消耗、接口调用次数等。
+ 买断制计费：<font style="color:rgba(0, 0, 0, 0.85);">一次性支付全部费用，获得商品的永久使用权或特定权益，如软件授权、资源包等。</font>



## 计费周期
### 镜像类商品
计费周期，即资源的最小购买单元。需要注意的是，服务商所提供的镜像服务计费周期或许存在差别，并且可能与云主机实例的计费周期并不相同。因此，将对计费周期进行统一设定：

1. 新购镜像及其部署的云主机实例，计费周期以镜像服务为准，云主机与镜像服务计费周期一致；
2. 续费镜像及其部署的云主机实例，计费周期细则参考 [续费周期](/cloudecosystem/buy/renew.md#续费周期) ；
3. 市场镜像仅支持按月、按年购买。

如您在资源缴费到期后未主动删除资源，且开通了自动续费功能，在账号余额充足的情况下，系统将默认为您扣除下一期的费用，资源有效期延长,具体细则见 [续费](/cloudecosystem/buy/renew?id=自动续费)。  
  
若账户余额不足，则资源到期后状态为已过期，具体规则见 [资源回收](/uhost/buy/recycle)。如您还需要保留镜像，请及时充值，手动续费的详细操作方式见 [续费镜像](/cloudecosystem/guide/buyerinfo?id=续费镜像)。

### 非镜像类商品
订阅制计费方式的商品的<font style="color:rgba(0, 0, 0, 0.85);">计费周期将按商品所支持的周期及您下单时实际选购的周期来确定，通常支持按月/按年。</font>
