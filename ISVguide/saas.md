# SaaS 类商品
SaaS 类商品是服务商通过配置的 URL 与云生态做接口调试后，进行商品的自动交付。用户购买后会接收到交付平台的 URL 地址，并通过服务商提供的账号密码和 URL 访问应用，直接使用服务。本文介绍服务商在云生态发布 SaaS 类商品的步骤。</font>

## 前置条件</font>
已完成入驻云生态 CloudEcosystem的商务沟通，确定接入方式，并正式签署合作协议。</font>

## 入驻步骤
**1.注册 UCloud 云平台账号** <br/>
注册UCloud 云平台账号，[详情参考](/register/register_flow)。</font>

**2.接入实施**  <br/>
该环节由生态团队协同服务商明确方案并实施，完成对应接口的开发与调测工作。</font>



**3.提交商品接入信息** <br/>
![](/images/Onboarding-saas.png)



**4.等待UCloud审核、配置商品** <br/>
UCloud 基于服务商提供的商品信息审核、发布。</font>

</font>

**5.定向发布测试账号** <br/>
将商品发布到指定测试账号以便进行测试。



**线上测试**  <br/>
测试商品的购买、创建、删除等功能，准备正式发布。



**正式发布**  <br/>
测试没有问题后正式全量发布，完成接入。
